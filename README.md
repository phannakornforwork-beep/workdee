# WorkDee

แพลตฟอร์มที่ช่วยให้ **เด็กจบใหม่ที่ยังไม่มีประสบการณ์ พิสูจน์กับบริษัทได้ว่าทำงานเป็น ก่อนถูกเรียกสัมภาษณ์**
และช่วย **SME 20–200 คนที่ไม่มีฝ่าย HR เต็มรูปแบบ** รับคนและบริหารทีมได้ในที่เดียว

> WorkDee lets graduates prove their skills with short, criteria-based work challenges before an interview,
> and gives small Thai companies a hiring pipeline plus a lightweight team workspace with delegated permissions.
> Next.js 15 (App Router) + Supabase (Postgres, Auth, Storage, Realtime) + Vercel.

ติดตั้งเป็นเว็บไซต์จริง: อ่าน **[docs/SETUP.md](docs/SETUP.md)** (ภาษาไทย ทีละขั้น)

---

## ทำอะไรได้บ้าง

**ผู้หางาน (พื้นที่ส่วนตัว)**
- โปรไฟล์ ทักษะ ผลงาน และการศึกษาที่ยืนยันด้วยเอกสาร
- ดูประกาศพร้อมช่วงเงินเดือน คะแนนความตรงกับงาน และอัตราการตอบผู้สมัครของบริษัท
- สมัครแล้วทำโจทย์สั้น ๆ จากงานจริง เห็นเกณฑ์ก่อนทำ แจ้งได้ว่าใช้ AI ส่วนไหน ได้คะแนนรายเกณฑ์และคำแนะนำ
- ใช้ผลโจทย์เดิมกับบริษัทอื่นที่เปิดรับได้ ไม่ต้องทำซ้ำ
- เลือกเวลาสัมภาษณ์เอง ขอเลื่อนได้ ตอบรับหรือปฏิเสธข้อเสนองาน
- แผนอาชีพ (ส่วน "ชีวิตส่วนตัว" ไม่ถูกส่งให้ใคร) ดาวน์โหลดข้อมูลทั้งหมด ถอนสิทธิ์บริษัท และลบบัญชีได้เอง

**บริษัท (พื้นที่บริษัท)**
- ลำดับชั้นตำแหน่ง สิทธิ์ผูกกับตำแหน่ง มอบต่อได้ไม่เกินที่ตัวเองมี (ไม่มี / แผนกตัวเอง / ทั้งบริษัท)
- เชิญทีมด้วยลิงก์ในกลุ่ม LINE อีเมล หรือไฟล์ Excel (CSV) พร้อมประวัติการเปลี่ยนแปลงที่แก้ไม่ได้
- ลงประกาศพร้อมโจทย์และเกณฑ์ กฎอนุมัติก่อนเผยแพร่ เปิดเวลาว่างให้ผู้สมัครเลือกนัดเอง
- กระดานผู้สมัครเรียงตามวันที่ต้องตอบ ตอบหลายคนพร้อมกันด้วยเหตุผลมาตรฐาน ยกเลิกได้ใน 30 วินาที
- กฎ 7 วัน: เตือนวันที่ 5 แจ้งเจ้าของวันที่ 6 ระบบปิดแทนวันที่ 7 และนับในอัตราการตอบที่แสดงต่อสาธารณะ
- งานของทีม (ใครทำอะไรอยู่ งานติดปัญหา) การลาและการอนุมัติ แชตบริษัทและแผนก ประกาศพร้อมดูว่าใครอ่านแล้ว
- ช่วงเวลาเงียบนอกเวลางาน: LINE/อีเมลรอส่งตอนเช้า ยกเว้นเรื่องด่วนกับคนที่ยินยอมไว้

**ผู้ดูแลระบบ** ตรวจหนังสือรับรองบริษัทและเอกสารวุฒิ ระงับหรือคืนสถานะบริษัท (`/admin`)

## หลักที่ตัดสินใจแล้ว (ไม่เปลี่ยน)

1. ไม่มีบัญชีดำพนักงานแชร์ระหว่างบริษัท
2. บัญชีเดียว แต่พื้นที่ส่วนตัวกับพื้นที่บริษัทแยกกัน นายจ้างปัจจุบันไม่เห็นว่าพนักงานกำลังหางาน
3. บริษัทต้องตอบผู้สมัครทุกคนภายใน 7 วัน และปฏิเสธต้องมีเหตุผลที่เป็นมาตรฐาน
4. ข้อมูลเป็นของผู้สมัคร บริษัทเห็นโปรไฟล์เต็มเฉพาะเมื่อสมัครหรือรับคำเชิญ
5. ช่อง "ชีวิตส่วนตัว" ในแผนอาชีพไม่ถูกแชร์ และไม่ใช้คัดกรอง

ข้อ 2–5 บังคับในฐานข้อมูลด้วย Row Level Security และฟังก์ชันที่ตรวจสิทธิ์ ไม่ได้พึ่งแค่หน้าเว็บ และมีชุดทดสอบยืนยัน

## โครงสร้าง

```
src/app/              หน้าเว็บ (Next.js App Router)
  me/                 พื้นที่ส่วนตัวของผู้หางาน
  c/[cid]/            พื้นที่บริษัท
  admin/              ผู้ดูแลระบบ
  api/cron/*          งานตามเวลา (กฎ 7 วัน สรุปประจำวัน ส่งแจ้งเตือน)
  api/line/webhook    รับข้อความจาก LINE Official Account (เชื่อมบัญชี)
src/lib/actions/      Server Actions (เรียกฟังก์ชันในฐานข้อมูล)
src/lib/notify/       ส่งอีเมล (Resend) และ LINE (Messaging API)
src/components/       ส่วนประกอบหน้าเว็บ
supabase/migrations/  โครงสร้างฐานข้อมูล สิทธิ์ และกติกาธุรกิจทั้งหมด (SQL)
tests/stack/          ระบบหลังบ้านแบบ Supabase สำหรับทดสอบ โดยไม่ต้องใช้ Docker
tests/api/            ทดสอบกติกาผ่าน API จริง
tests/smoke/          เปิดทุกหน้าหลักด้วยข้อมูลจริงหลัง build
```

**หลักการออกแบบ**
- กติกาธุรกิจอยู่ในฐานข้อมูล (ฟังก์ชัน `security definer` ที่ตรวจสิทธิ์ทุกครั้ง) หน้าเว็บเป็นแค่ตัวเรียกใช้ จึงปลอดภัยแม้มีคนยิง API ตรง
- สิทธิ์ผูกกับตำแหน่ง ไม่ผูกกับคน ลดสิทธิ์ตำแหน่งไหน ตำแหน่งที่อยู่ใต้ลงไปถูกลดตาม
- การแจ้งเตือนเข้าคิว (outbox) แล้วส่งตามช่วงเวลาที่อนุญาต จึงไม่หายและไม่ส่งซ้ำ
- ไฟล์ทุกไฟล์เป็นแบบส่วนตัว เปิดดูผ่านลิงก์ที่หมดอายุใน 10 นาที

## พัฒนาในเครื่อง

ต้องมี Node.js 20.9 ขึ้นไป และเลือกฐานข้อมูลแบบใดแบบหนึ่ง

**แบบ A: Supabase CLI (ใช้ Docker)**
```bash
npm install
npx supabase start            # ได้ URL และคีย์ของเครื่อง
npx supabase db reset         # รัน migration ทั้งหมด
cp .env.example .env.local    # ใส่ URL และคีย์ที่ได้
npm run dev
```

**แบบ B: ไม่ใช้ Docker** (ต้องมี PostgreSQL 16 และ `psql` เปิดที่พอร์ต 54322 ผู้ใช้ `postgres` รหัส `postgres`)
```bash
npm install
npm run stack:up              # เปิด Auth + REST + Storage จำลองที่ http://127.0.0.1:54321 (ค้างไว้)
# คีย์อยู่ใน .stack/keys.env → ใส่ใน .env.local
#   NEXT_PUBLIC_SUPABASE_URL=http://127.0.0.1:54321
#   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=<SUPABASE_ANON_KEY>
#   SUPABASE_SECRET_KEY=<SUPABASE_SERVICE_ROLE_KEY>
npm run dev
```
แบบ B ไม่มีแชตแบบเรียลไทม์ (ข้อความขึ้นเมื่อส่งหรือรีเฟรช) อีเมลยืนยันถูกข้ามอัตโนมัติ

## ทดสอบ

```bash
npm run db:reset      # ล้างและสร้างฐานข้อมูลทดสอบใหม่ (แบบ B)
npm run test:api      # 38 กรณี: สิทธิ์ ความเป็นส่วนตัว การสมัครงานครบวงจร กฎ 7 วัน แจ้งเตือน ไฟล์ งานของทีม
npm run typecheck
npm run build && npx next start &   # แล้ว
npm run test:smoke    # เปิดทุกหน้าหลักด้วยบัญชีผู้หางาน บริษัท และผู้ดูแลระบบ
```
GitHub Actions รันทั้งหมดทุกครั้งที่ push (`.github/workflows/ci.yml`)

## สิ่งที่ยังไม่ทำ (ระยะถัดไป)

- หน้าเว็บสำหรับเจ้าหน้าที่สถาบันการศึกษายืนยันวุฒิ (ฐานข้อมูลรองรับแล้ว ตอนนี้ผู้ดูแลระบบตรวจเอกสารแทน)
- บริษัทค้นหาและเชิญผู้หางานที่เปิดให้ค้นหา
- งานระยะสั้น (gig): คะแนนความน่าเชื่อถือ การจ่ายเงิน
- ระบบชำระเงินของบริษัท และ SMS สำหรับเรื่องด่วน
- หนังสือรับรองการทำงานและหนังสือเตือน ที่ส่งต่อได้เฉพาะเมื่อเจ้าตัวยินยอมทีละครั้ง
